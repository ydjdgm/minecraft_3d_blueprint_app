# Blockcraft — 마인크래프트 3D 설계도 스튜디오

현재 릴리스: **26.2v1** · [공개 사이트](https://blockcraft-blueprint-studio.ydjdgm.chatgpt.site/)

한국어 웹 앱. `studio/`에서 실행합니다.

```sh
cd studio
npm run install:ci
npm run dev
```

미리보기: http://localhost:5173

- 3D 블록 배치·삭제, 회전·확대·이동, 좌표 입력 및 방향 저장
- 40단계 실행 취소/다시 실행, 기기 내 자동 저장
- 전체 재료 수량, 스택 환산, 준비 체크리스트
- 높이별 누적 보기와 단일 층 보기
- 서버에 저장한 설계도 사본을 링크로 공유·미리보기·보관함에 추가
- 다크·라이트 모드, 반응형 편집 화면
- OpenAI·Anthropic Claude·Google Gemini를 이용한 자연어 생성·수정과 적용 전 변경 제안

추가된 편집·건축 도구: 설계도별 준비 상태 저장, 이름·영역 편집 실행 취소, 시점 전체 맞춤, 계단·반 블록·통나무 형상, 여러 설계도 보관함과 파일 백업, 영역 채우기·삭제·교체, 층별 2D 건축 가이드, AI 변경 위치 미리보기. 사용법과 지원 범위는 [스튜디오 설명](studio/README.md#편집건축-도구)을 참고하세요.

## AI 설정과 하네스

앱의 **AI 설계 → API 키 연결하기**에서 제공업체를 선택하고, 해당 업체의 API 키와 구조화 출력을 지원하는 모델 ID를 입력합니다. OpenAI, Anthropic Claude, Google Gemini를 지원하며 모델 ID는 직접 수정할 수 있습니다. 설정 완료는 입력값 보관이며, 실제 인증은 설계 요청 시 확인합니다.

키와 모델 설정은 제공업체별로 탭 메모리에만 보관하며 새로고침하면 초기화됩니다. 업체를 바꾸면 그 업체에 입력했던 설정으로 전환됩니다. **이 제공업체의 키 지우기**로 선택한 키를 제거할 수 있습니다. 요청 시 선택한 업체의 키와 설계도만 같은 출처의 앱 서버를 거쳐 해당 업체로 전송합니다. 키를 로그나 저장소에 기록하지 않으며, API 이용 요금은 해당 키의 계정에 부과됩니다. 서버 공용 키는 필요하지 않습니다. 임의 API 주소, Azure OpenAI, Bedrock, Vertex AI 등 별도 게이트웨이는 현재 지원하지 않습니다.

하네스는 현재 블록 문맥, 허용 블록 목록, 좌표 체계와 명령 스키마를 모델에 전달합니다. `set`, `remove`, `fill`만 허용하고 좌표·방향·연산량·최종 크기를 서버와 클라이언트에서 검증합니다. 검증 실패 시 최대 한 번 수정 요청 후 실패를 표시하며, 변경은 전부 적용하거나 전혀 적용하지 않습니다. 생성 중 설계도가 바뀌면 오래된 제안을 버립니다. 사용자가 적용한 결과도 실행 취소할 수 있습니다.

API별 지원 범위와 확장 방법은 [AI 연결 문서](studio/docs/ai-providers.md)를 참고하세요.

## 현재 범위

Java Edition 26.2의 전체 등록 아이템 1,537종과 설치 가능한 1,094종을 지원합니다. 전체 아이템 사전에서 이름·ID·설치 여부·제작법을 검색할 수 있습니다. 팔레트는 설치 가능한 항목만 표시합니다. 제작법 1,536개를 바탕으로 공통 하위 재료를 합산하고 조합 횟수·남는 수량·대체 재료를 계산합니다. 철 블록 2개는 기본 설정에서 철 주괴 18개로 계산됩니다. 준비 방법을 직접 준비 또는 다른 제작법으로 변경할 수 있습니다. 출처·분류·계산 규칙은 [데이터 설명](studio/docs/minecraft-data.md)을 참고하세요.

축별 좌표 0–47, 설계도 최대 16,000블록, AI 입력 최대 4,000블록. 설치물은 단순화된 형상이며 전체 blockstate, 레드스톤·유체·중력 시뮬레이션은 포함하지 않습니다. 공유 링크는 이 앱 전용이며 `.schematic`, `.litematic` 또는 게임 내 자동 배치 기능이 아닙니다. 작업 보관함은 브라우저별 로컬 저장이며, 공유 사본만 서버의 D1 저장소에 보관합니다. 연료와 상태에 따라 달라지는 특수 제작법은 계산에서 제외하며 앱에 이를 표시합니다.

## 확인

```sh
cd studio
node scripts/check-core.mjs
node scripts/check-ai.mjs
node scripts/check-materials.mjs
node scripts/check-editor.mjs
node scripts/check-sharing.mjs
npx tsc --noEmit
npm run build
```

코어 테스트는 한글 설계도 왕복, 손상 데이터, 중복 좌표, 범위·예산 제한, 원자적 편집, 서버 출처·키 검증, 모의 AI 응답과 최대 1회 복구를 검증합니다. 실제 유료 API 호출과 브라우저 상호작용 테스트는 별도로 필요합니다. 선택적 WebMCP 읽기 도구는 지원 브라우저에서만 등록하며 현재 환경에서 실제 등록 검증을 수행하지 않았습니다.
