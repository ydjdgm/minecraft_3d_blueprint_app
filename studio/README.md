# Blockcraft — 마인크래프트 3D 설계도 스튜디오

현재 릴리스: **26.2v1** (패키지 버전 `26.2.1`) · [공개 사이트](https://blockcraft-blueprint-studio.ydjdgm.chatgpt.site/)

한국어 웹 앱. `studio/`에서 실행합니다.

```sh
cd studio
npm run install:ci
npm run dev
```

미리보기: http://localhost:5173

- 3D 블록 배치·삭제, 회전·확대·이동, 좌표 입력 및 방향 저장
- 40단계 실행 취소/다시 실행, 기기 내 자동 저장
- 전체 재료 수량, 스택 환산, 준비 체크리스트
- 높이별 누적 보기와 단일 층 보기
- 서버에 저장한 설계도 사본을 링크로 공유·미리보기·보관함에 추가
- 다크·라이트 모드, 반응형 편집 화면
- OpenAI 모델을 이용한 자연어 생성·수정과 적용 전 변경 제안

## 편집·건축 도구

- **보관함**: 설계도 최대 100개를 기기 내에 자동 저장하고 열기·복제·삭제합니다. 기존 단일 자동 저장 설계도를 처음 실행할 때 이전합니다. 전체 JSON 파일 백업·복원에는 설계도별 재료 체크, 제작법 선택, 층 완료 상태가 포함됩니다. 복원은 확인 후 보관함 전체를 교체하며, 삭제는 확인 후 진행합니다. 저장 용량은 브라우저에 따라 다릅니다.
- **편집 이력**: 이름은 Enter 또는 포커스 이동 시 확정합니다. 이름 변경과 영역 편집을 포함해 최근 40개 작업을 실행 취소합니다. 빈 좌표 삭제 등 실제 변화가 없는 작업은 이력을 소비하지 않습니다. 다른 설계도를 열면 해당 작업 세션의 이력은 초기화됩니다.
- **전체 맞춤**: 설계도 위치와 크기에 맞춰 시점과 확대율을 계산합니다.
- **형상 표시**: 계단은 북·남·동·서 방향의 두 단, 반 블록은 위 방향일 때 상단·그 외 하단, 통나무는 방향에 따른 축과 단면을 표시합니다. 계단의 위·아래 방향 값은 북쪽으로 표시합니다. 전체 blockstate나 게임의 설치 규칙을 재현하지는 않습니다.
- **영역 편집**: 두 좌표 사이를 채우기·삭제하거나 기존 재료만 교체합니다. 양 끝 좌표를 포함하며 순서는 무관합니다. 교체는 빈칸을 유지하고 특정 재료 또는 모든 재료를 대상으로 합니다. 16,000블록 한도를 적용 전에 검사합니다.
- **층별 건축 가이드**: Y=0–47의 위에서 본 격자, X/Z 좌표, 재료 번호와 수량을 표시합니다. 완료 표시는 해당 층의 블록·방향과 함께 저장되어 내용이 바뀌면 해제되어 보입니다.
- **AI 미리보기**: 초록은 추가, 빨강 점선은 삭제, 노랑은 재료·방향 교체입니다. 가려진 변경 위치도 윤곽선으로 표시합니다. 제안 적용 전에는 3D 클릭 편집을 잠시 막으며, 좌표·영역 편집 등으로 문서가 바뀌면 제안을 폐기합니다.

재료 체크와 제작법 선택은 탭 전환·새로고침 후에도 유지됩니다. 준비 수량이 바뀐 항목은 새 수량 기준으로 체크되지 않은 상태로 표시됩니다. API 키는 보관함과 백업에 포함하지 않습니다.

## AI 설정과 하네스

앱의 **AI 설계 → API 키 연결하기**에서 자신의 OpenAI API 키와 구조화 출력을 지원하는 모델 ID를 입력합니다. 키는 탭 메모리에만 보관합니다. 설계 요청 시 같은 출처의 서버를 거쳐 OpenAI Responses API로 전송하며 로그나 저장소에 기록하지 않습니다. API 이용 요금은 해당 키의 계정에 부과됩니다. 서버 공용 키는 필요하지 않습니다.

하네스는 현재 블록 문맥, 허용 블록 목록, 좌표 체계와 명령 스키마를 모델에 전달합니다. `set`, `remove`, `fill`만 허용하고 좌표·방향·연산량·최종 크기를 서버와 클라이언트에서 검증합니다. 검증 실패 시 최대 한 번 수정 요청 후 실패를 표시하며, 변경은 전부 적용하거나 전혀 적용하지 않습니다. 생성 중 설계도가 바뀌면 오래된 제안을 버립니다. 사용자가 적용한 결과도 실행 취소할 수 있습니다.

API 참고: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

## 현재 범위

Java Edition 26.2의 전체 등록 아이템 1,537종과 설치 가능한 1,094종을 지원합니다. 전체 아이템 사전에서 이름·ID·설치 여부·제작법을 검색할 수 있습니다. 팔레트는 설치 가능한 항목만 표시합니다. 제작법 1,536개를 바탕으로 공통 하위 재료를 합산하고 조합 횟수·남는 수량·대체 재료를 계산합니다. 철 블록 2개는 기본 설정에서 철 주괴 18개로 계산됩니다. 준비 방법을 직접 준비 또는 다른 제작법으로 변경할 수 있습니다. 출처·분류·계산 규칙은 [데이터 설명](docs/minecraft-data.md)을 참고하세요.

축별 좌표 0–47, 설계도 최대 16,000블록, AI 입력 최대 4,000블록. 설치물은 단순화된 형상이며 전체 blockstate, 레드스톤·유체·중력 시뮬레이션은 포함하지 않습니다. 공유 링크는 이 앱 전용이며 `.schematic`, `.litematic` 또는 게임 내 자동 배치 기능이 아닙니다. 작업 보관함은 브라우저별 로컬 저장이며, 공유 사본만 서버의 D1 저장소에 보관합니다. 연료와 상태에 따라 달라지는 특수 제작법은 계산에서 제외하며 앱에 이를 표시합니다.

코어 테스트는 한글 설계도 왕복, 손상 데이터, 중복 좌표, 범위·예산 제한, 원자적 편집, 서버 출처·키 검증, 모의 AI 응답과 최대 1회 복구를 검증합니다. 실제 유료 API 호출과 브라우저 상호작용 테스트는 별도로 필요합니다. 선택적 WebMCP 읽기 도구는 지원 브라우저에서만 등록하며 현재 환경에서 실제 등록 검증을 수행하지 않았습니다.

## 링크 공유

공유하기에서 로그인 후 현재 설계도의 링크를 만듭니다. 공유 사본은 생성 시점에 고정됩니다. 링크를 받은 사람은 `/share/:id`에서 3D와 재료를 미리보고 자신의 기기 보관함에 새 설계도로 추가합니다. 작업 중인 원본, API 키, 재료 준비 상태는 공유되지 않습니다. 기존 문자열 코드 공유·가져오기는 제거했습니다. 전체 보관함의 파일 백업·복원은 그대로 사용할 수 있습니다.

같은 계정으로 로그인하면 만든 링크를 관리할 수 있습니다 (활성 링크 최대 100개). 공유 해제는 서버의 사본 내용을 지우고 이후 조회를 차단합니다. 해제된 ID는 재사용하지 않으며, 다른 사람이 이미 보관함에 복사한 문서는 삭제하지 않습니다. 공유 조회에는 캐시를 사용하지 않습니다. ID는 임의의 128비트 값이며, 공개 검색·목록 기능은 없습니다.

사이트 자체의 접근 정책도 적용됩니다. 본인 전용 사이트에서는 다른 사람이 링크를 열 수 없습니다. 외부 공유에는 배포 및 사이트 접근 정책 변경이 필요합니다. localhost에서 만든 링크는 로컬 테스트용이며 배포 사이트로 자동 이전되지 않습니다.

D1 바인딩은 `DB`이며 `drizzle/0000_perpetual_silvermane.sql`로 공유 테이블을 생성합니다. 배포 시 플랫폼이 마이그레이션을 적용합니다. 로컬 개발에서는 빌드 후 README의 표준 Wrangler D1 명령으로 이 마이그레이션을 한 번 적용해야 합니다. `node scripts/check-sharing-http.mjs`는 localhost:5173에서 미리보기 전용 모의 계정으로 생성·조회·해제를 검증합니다. 실제 ChatGPT 로그인과 공개 배포 접근은 별도 확인이 필요합니다.
